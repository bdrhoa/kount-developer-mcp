# Triage labels

Use the GitHub label mapped to the canonical role named by the skill.

| Canonical role    | GitHub label      | Meaning                                      |
| ----------------- | ----------------- | -------------------------------------------- |
| `needs-triage`    | `needs-triage`    | A maintainer needs to evaluate the issue     |
| `needs-info`      | `needs-info`      | More information is needed from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent       |
| `ready-for-human` | `ready-for-human` | Requires human implementation                |
| `wontfix`         | `wontfix`         | The issue will be closed without action      |
